# 花卷的主页

这是我给小猫花卷做的一张互联网名片。

一开始只是想写个简单的自我介绍页，后来越改越觉得，普通的“头像 + 三行文字”不太像花卷。于是慢慢加了作品、今日签、生活照片、留言和一些小交互，最后变成了现在这个有点像作品集、又有点像猫咪生活档案的主页～

在线地址：<https://lemoberry.github.io/huajuan-homepage/>

## 现在页面里有什么小巧思

- 首页固定放花卷的第一张主图。电脑上用正方形构图，手机上把打字标题放到图片前面，打开主页或再次点击“简介”都会重新打字。
- “今日签”里准备了 12 条柔软提示，抽签时会避开刚刚出现过的那一条，也可以直接复制结果。
- 技能区可以展开“花卷的一天”，不想让信息一上来全挤在页面里。
- 作品区不只是两张静态卡片，还能临时添加项目；数量会跟着新增内容变化。
- 生活照片支持双击看大图，也可以从本地添加新照片。图片会先压缩再保存，避免浏览器存储很快被塞满。
- 留言、临时项目和新增照片都保存在当前浏览器的 `localStorage` 里。这个项目没有后端，所以换浏览器或清理网站数据后不会同步。
- 页面上下滑动时，顶端的彩色进度条也会跟着变化，方便看出当前浏览到了哪里。
- 还有浅色 / 深色主题、返回顶部、键盘操作和减少动画偏好适配。

## 这个页面是怎么来的

我把过程留在 Git 历史里了。中间有些方案最后没留下，但它们也确实影响了现在的样子。

- `51ce217`：最初版本上线。当时基本就是一份能打开的花卷介绍页，先把内容和照片放到网页上再说。
- `b3ce03b`：把“介绍页”往作品集方向推了一步。重新组织了首屏、作品、能力和联系区，也开始用更明确的视觉层级讲花卷是谁。
- `ccedd08`：把挤在 HTML 里的样式和脚本拆成 `style.css`、`script.js`，顺便补上深色主题、展开收起、返回顶部和键盘焦点。这个版本也刻意写了适合初学者阅读的注释。
- `cee0208`：加入“今日花卷签”。随机结果不会连续重复，卡片会有一个很轻的弹出反馈，让抽签不是单纯换一行文字。
- `38e4fae`：把长页面改成更像小应用的分区导航。地址栏仍然保留 `#intro`、`#skills` 这样的链接，所以刷新和分享不会丢位置；同时加了标题打字、滚动进度、当前导航状态、签文复制和图片大图查看。
- `58cfabe`：加入 6 张生活照片和真正可操作的内容区。项目、留言、照片都能在浏览器里新增或删除；上传图片会经由 Canvas 缩小后再存储。照片的双击放大和键盘打开共用同一套逻辑，没有给每张图重复写事件。
- `ccad37e`：修正电脑端简介图被图片原始高度拉成长条的问题，第一次开始单独处理桌面图片比例。
- `1628cce`：尝试过统一的正方形照片框，并给不同照片设置不同裁切中心。这个版本让我确认了一件事：同一套裁切参数并不适合每张猫图。
- `8d46957`：又试过让边框跟随横图、竖图变化，并给轮播加预加载和淡入淡出。切换顺了，但首页一直变化反而有点抢内容。
- `51c90b5`：最后取消轮播，固定第一张图。代码更少，页面也安静下来；同时让每次回到简介页时都能重新看到标题打字，而不是只有第一次加载才播放。
- `91aeb23`：针对手机重新排了首屏顺序，让小标签和打字标题先出现，再看到照片，正文和按钮仍放在后面。桌面布局没有跟着改。

## 本地打开

这是纯静态项目，没有安装依赖，也没有构建命令。直接双击 `index.html` 可以看；如果浏览器对本地文件有限制，可以在项目目录运行：

```bash
python3 -m http.server 8000
```

然后访问 <http://localhost:8000/>。

主要文件很少：

- `index.html`：页面内容和结构
- `style.css`：桌面、手机、深色主题和动画
- `script.js`：导航、打字、今日签、图片查看和本地存储
- `assets/`：花卷的照片

部署使用 GitHub Pages，来源是 `main` 分支根目录。推送到 `main` 后，线上页面会自动更新。
